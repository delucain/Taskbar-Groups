Taskbar Groups - Complete Framed Group Icon Library

This folder contains framed group-icon variants of every icon in the original
Icon Library. The original artwork is preserved and composited with the same
standardized rounded-square group frame approved for the initial six icons.

Recommended project location:
    Icon Library\Group Icons\

Keep the original unframed icons in Icon Library for ordinary shortcut/item
icons. Use these framed variants for group/taskbar shortcuts.
